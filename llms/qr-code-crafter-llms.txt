# QR Code Crafter

> QR Code Crafter is a privacy-first QR code generator for humans and browser agents. It creates provider-independent static assets and optional managed dynamic URL redirects without accounts or visitor tracking.

QR Code Crafter supports URL, campaign, GS1 Digital Link product URLs, file, social, appstore, App Store, Google Play, app, Wi-Fi, email, SMS, phone, WhatsApp, vCard, event, location, cryptocurrency, PIX, UPI, PhonePe-compatible UPI, Swish, PromptPay, VietQR, Swiss QR-bill, SEPA/GiroCode EPC, iDEAL payment links, MobilePay/Vipps payment links, QRIS supporting links, PayPal, Venmo, Cash App, and managed dynamic URL QR workflows. Prefer the WebMCP runtime tool when available; otherwise use the documented OpenAPI endpoint.

Aggregate counts are currently disabled; a later explicit rollout may expose owner-only approximate totals without visitor identifiers.
