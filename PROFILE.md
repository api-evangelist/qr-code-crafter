## APIs

- **QRCodeCrafter API** — REST API for generating static and bulk QR codes and managing dynamic URL redirects/vaults with aggregate analytics. Includes an OpenAPI 3.0.1 contract, WebMCP browser-agent context, ai-plugin.json, llms.txt, and ai.txt agent guides. (`https://qrcodecrafter.com`)

> REST API with confirmed live OpenAPI 3.0.1 at /.well-known/openapi.json (YAML advertised at /openapi.yaml but not separately confirmed). Generation endpoints are public/no-auth Netlify Functions; dynamic QR management uses capability-token bearer auth. Agent-native surfaces confirmed: llms.txt and ai.txt (https://qrcodecrafter.com/ai.txt) are live, plus a legacy ai-plugin.json. The advertised 'WebMCP' (/.well-known/webmcp.json v1.0.0) is a browser-side WebMCP tool context (registered via navigator.modelContext.registerTool), NOT a remotely-connectable hosted MCP server, so it is not cataloged as an MCP property; local QA runs via 'npm run test:local-webmcp'. No AsyncAPI, GraphQL, Postman collection, or published agent skills found. apis.json is live at https://qrcodecrafter.com/apis.json. Rate limiting is cost-weighted per client (default 180 units / authenticated 600 units per 60s).
